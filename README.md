# Shift Scheduler Portfolio

複数スタッフの希望と必要人数を見比べながら、2週間のシフト案を確認するためのフロントエンドデモです。

## Demo

`index.html` をブラウザーで開くと動作します。GitHub Pagesにも、そのまま公開できます。

## 見どころ

- 2週間の配置状況を一覧表示
- 日ごとの必要人数と配置人数を比較
- 不足枠を視覚的に警告
- スタッフの希望状態（出勤可・時間指定・休み）を表示
- 部門別の配置人数を集計
- 画面幅に応じたレスポンシブ表示

## 公開用の安全設計

このリポジトリは、実運用版とは別にゼロから作成した閲覧専用デモです。

- 人名、店舗名、勤務条件、時給、売上、人件費、連絡先はすべて架空
- 実運用API、データベース、クラウドURL、環境変数を含まない
- PIN、パスワード、トークンなどの認証情報を含まない
- 実運用リポジトリのGit履歴やコミットを引き継がない
- データの保存・送信機能はなく、ブラウザー内のサンプルデータだけを使用

## 技術構成

- HTML
- CSS
- Vanilla JavaScript
- 外部ライブラリなし

## ローカル確認

`index.html` を直接開くか、任意の静的ファイルサーバーでこのフォルダを配信してください。

## 公開手順

1. GitHubで空の `shift-scheduler-portfolio` リポジトリを作成する
2. このフォルダの中身だけを新規リポジトリへ追加する
3. GitHub PagesのSourceを `Deploy from a branch`、Branchを `main / (root)` にする

実運用版からclone、fork、mirror、履歴付きコピーは行わないでください。

## 注意

本デモはポートフォリオ用です。自動割当の最適化、厳密な労務制約、本人認証、永続化は実装対象外です。
